CODEAMANI LABS · product testing

DoseVault.health tests on invented people.

DoseVault.health is Labs’ medication administration product for Florida group-home operations. It holds real ePHI in production. This public seed exists so we never have to use that data to find bugs.

Commitment

CODEAMANI LABS ships DoseVault only after flows have been exercised on synthetic residents, providers, clinics, pharmacies, and medications:

  • No real names, dates of birth, SSNs, Medicaid IDs, or NPPES rows in fixtures, git, or chat.
  • Training Postgres is a separate Neon project (dosevault-synthetic). HIPAA is off there.
  • Production ePHI stays on the HIPAA-enabled medtrack project, covered by Neon’s BAA.
  • The seeder refuses to load into the production project id.
  • Preview deploys of DoseVault are labeled and do not publish over dosevault.health until a human promotes them.
Privacy is not a banner on the marketing site. It is the rule that test data and live resident data do not share a database, a git history, or a Netlify production alias.

What DoseVault uses this set for

  • Facesheet and provider-card layout with crowded, realistic (but fake) identities
  • MAR schedules using the fake formulary (indication, dose, PRN, times)
  • Reminder jobs that must not fire against live phone numbers from a training load
  • Performance checks at 10k patient scale before touching production

What this is not

This site is not DoseVault’s clinical app, not an AHCA or APD extract, and not a de-identified dump of T&T Serenity Care records. If you are a covered entity, you still need your own BAA stack for live PHI. We published the generator so you can build the same wall between test and care.
