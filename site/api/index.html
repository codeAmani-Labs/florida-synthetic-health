Public, read-only JSON on GitHub Pages plus the Python generator and SQL schema. All payloads are synthetic. Do not send these identifiers to a live EHR as if they were real.

OpenAPI

Machine-readable contract: api/v1/openapi.yaml. Import it into any OpenAPI viewer. Responses always include "synthetic": true.

Python CLI

Package entry: python -m florida_seed (src/florida_seed).

CommandWhat it does
seed --csv-onlyWrite CSV under data/generated/
seed --loadCOPY into DATABASE_URL or NEON_SYNTHETIC_DATABASE_URL
fetch-syntheaDownload MITRE’s 100-patient CSV sample

The loader exits 3 if the DSN looks like Labs’ HIPAA production project (medtrack / steep-water-27074984).

from florida_seed.meds import FORMULARY
from florida_seed.cli import generate
bundle = generate(seed=42, patients=100, homes=10, clinics=4, pharmacies=4, providers=20)
assert all(d["ndc_synth"].startswith("99999-") for d in FORMULARY)

SQL schema

  • sql/001_schema.sql — homes, clinics, pharmacies, providers, patients
  • sql/002_med_catalog.sql — drug_catalog + MAR-shaped medications

Medication columns include generic_name, used_for, indication, form, strength, route, dose_amount, frequency, scheduled_times, directions, warnings, prn, ndc_synth, prescriber, pharmacy, start date.

CSV fixtures

Tiny checked sample (20 lives) in fixtures/tiny/. Do not treat it as a real household.

Privacy. These resources are for software testing. Combining them with real resident identifiers, or loading them into a production HIPAA database, is out of scope and refused by Labs’ seeder.
