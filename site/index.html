Why Labs published this

Real AHCA, APD, NPPES, and EHR extracts are the wrong source for fixtures. This generator is how DoseVault.health is tested, and it is public so other Florida builders can do the same.

Invalid on purpose

SSNs use area 666. Medicaid IDs are FLTEST. NPIs are SYNTH- tokens. Licenses are TEST-AHCA-. NDC labeler 99999.

Isolated from production

Labs loads this set into a non-HIPAA Neon project. The seeder refuses the DoseVault production database id.

Faker + optional Synthea

Default 10k lives are Florida geography + Faker. Optional MITRE Synthea CSV import for richer clinical overlay (Apache-2.0).

Full MAR-shaped meds

Forty invented generics with class, indication, dose, route, sig, warnings, PRN, and fill fields — not real INNs.

Generate locally

python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
PYTHONPATH=src .venv/bin/python -m florida_seed seed --patients 10000 --seed 42 --csv-only
# or load a training Postgres (never HIPAA production):
export DATABASE_URL=postgresql://…
PYTHONPATH=src .venv/bin/python -m florida_seed seed --patients 10000 --load
